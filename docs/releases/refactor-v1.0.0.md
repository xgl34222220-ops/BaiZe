# 白泽重构版 1.0.0 正式版

**重构版 1.0.0 是当前公开版本线的第一个正式版本。**

内部构建号：**30003**。模块 ID、App 包名与正式签名保持稳定，后续重构版将沿用同一升级链。

## 全新界面

- 首页、设置页与底部导航统一为洛书同源的 MIUIX / 液态玻璃视觉。
- 悬浮底栏使用同源折射、模糊、选中透镜、缩放与弹簧动画。
- 详情页进入后隐藏一级底栏，返回时恢复正确选中状态。
- 保留深色模式、动态取色与不支持实时玻璃设备的稳定降级方案。

## 扫描结果与选择

- 明确区分实时扫描、历史记录、过期快照和部分未完成任务。
- 旧记录显示为历史结果，不再冒充当前剩余垃圾量。
- 常驻“全选低、中风险”和“仅选中风险”。
- 普通高风险项目默认不选，必须逐项选择并再次确认。
- 保护项明确显示不可选原因，不通过隐藏项目制造“清理干净”的假象。

## 白名单管理

- 统一管理“应用保护”和“路径保护”。
- 应用保护可按应用增量保存，不覆盖其他入口同时添加的保护。
- 路径保护支持逐条移除，只删除精确白名单记录，不连带移除父目录、子目录或应用保护。
- 取消保护不会删除应用或文件。
- 白名单读取失败、Root 断线或结果未确认时禁止写入和自动重试。
- 修改白名单后旧扫描快照立即失效，必须重新扫描后才能继续清理。

## 清理与安全

- 保留应用缓存、系统垃圾、深度规则、安装包、卸载残留、文件归类、自动任务、任务历史、隔离与审计能力。
- 低、中、高、关键四级风险继续独立处理。
- 自动任务不会执行高风险和关键风险项目。
- 清理前继续校验快照、文件状态、符号链接、白名单和关键数据保护。
- 只有真正删除成功的内容才计入释放空间与统计。

## 安装

完整使用建议下载并刷入：

- `BaiZe-v1.0.0-Module.zip`

仅更新 App 可安装：

- `BaiZe-v1.0.0.apk`

模块内置 App 与独立 APK 字节一致，并提供 SHA-256 与正式签名证书信息。

正式发布流程已完成：

- 单元与界面测试
- Android lint
- 原生引擎与 Shell / Python 核心回归
- Android 16 模拟器实际安装、冷启动与前后台切换
- 正式签名证书校验
- 模块内置 APK 与独立 APK 一致性校验
- SHA-256 校验

模拟器验证不能替代所有品牌和 ROM 的 Root、GPU 与后台策略真机测试；如遇兼容问题，请附系统版本、Root 方案、白泽版本和脱敏后的错误信息。
