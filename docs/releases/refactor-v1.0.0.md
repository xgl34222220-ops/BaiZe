# 白泽重构版 1.0.0 正式版

内部构建号 **30003**，沿用旧正式签名与应用/模块 ID。支持从 3.0.0 / 30002 覆盖升级，不卸载、不清数据、不重置清理计划。

## 扫描结果与选择

- 区分历史记录、快照过期和部分未完成，不再一律显示“有项目需要核对”。旧记录及原大小明确标注为历史扫描，不代表剩余垃圾。
- 常驻“全选低、中风险”和“仅选中风险”；不能操作时显示连接、读取、过期等具体原因。
- 全是普通高风险的分组显示“逐项选择”，保护项显示“查看原因”。保留逐项高风险确认及关键数据限制，不自动全选高风险。
- 新增白名单管理入口，进入后使旧快照失效，返回重新扫描后才可清理。

## 白名单管理

- 统一“应用保护 / 路径保护”页面。取消应用勾选后保存；取消全部应用保护需确认，不删除应用或文件。
- 手动路径保护可逐条确认移除，只移除精确记录，不连带取消父目录、子目录或应用保护，也不删除路径对应文件。
- 应用增量保存保留其他入口并发添加的保护；已卸载或不可见的受保护应用也保留在管理列表。
- 读取失败不当作空名单，断线禁止写入；操作结果未确认时不自动重试。

保留洛书同源首页、设置、液态玻璃底栏及 30002 启动闪退修复。清理引擎、规则和关键数据限制未更改。

## 安装

直接覆盖安装本版 APK；完整更新请在 Root 管理器刷入本版模块 ZIP 后重启。模块内置 App 与独立 APK 字节一致。

## 版本与验证

正式版本序列：**1.0.0 → 1.1.1 → 2.0.0 → 2.2.2 → 3.0.0 → 3.3.3…**；构建号独立递增，标签使用 refactor-v 前缀。

发布要求单元/界面测试、核心回归、lint、原签名与校验值检查、内置 APK 一致性检查，以及 Android 16 模拟器上实际安装最终签名压缩包，验证 30002 覆盖升级、数据保留、冷启动、页面切换、白名单页面、新安装和前后台切换。具体结果以本次工作流为准。

模拟器不等于 K80 至尊版、一加 15 的 Root 清理与 GPU 真机验收，本次不声称这两台手机已完成验证。
