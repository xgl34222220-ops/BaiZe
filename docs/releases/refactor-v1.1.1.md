# 白泽重构版 v1.1.1

这是重构版第二个正式版本，重点修复实际清理链路并统一界面体验。

## 安装包扫描与清理

- 修复 Android 16 / HyperOS 上安装包可能扫描不到的问题。
- 优先扫描真实共享存储 `/data/media/<user>`，必要时回退 `/storage/emulated/<user>`。
- 补充 `/data/local/tmp`、可移动存储等来源。
- 支持 APK、APKS、XAPK、APKM、AAB 安装文件。
- 单个扫描根目录读取异常时，不再直接丢弃其他已经发现的结果。
- 安装包扫描与清理继续共享同一允许根目录，清理基于扫描快照和文件身份校验，避免误删扫描后发生变化的文件。

## 清理可靠性

- 保留应用缓存、系统垃圾、深度清理、卸载残留、文件归类、定时任务、任务历史、白名单与隔离能力。
- 核心清理回归、APK 扫描契约、APK 调度、覆盖范围和任务锁测试全部通过。
- App 与 Root 模块按同一源码版本配套构建，避免 App 已更新但底层清理脚本仍停留在旧版。

## 界面

- 默认 MIUIX 界面全面统一为洛书设计语言。
- 首页、清理、记录、设置、外观与主题统一卡片、字号、页头、图标槽和交互层级。
- 保留 Material 兼容模式，不影响 Root 清理引擎和规则逻辑。

## 验证

- 完整核心清理回归通过。
- Android UI CI、Kotlin 编译和 lint 通过。
- 原生清理引擎构建通过。
- 正式签名 APK 与模块内嵌 APK 一致性校验通过。
