# 白泽 2.0.0 正式版

本次整合新版清理界面，整理模块结构，并采用已确认的白泽新图标。

- 统一首页、清理、记录、设置及工具页面的配色、卡片、分类图标、弹窗和空状态；支持紧凑全选底栏，处理系统栏避让和大字体布局。
- 扫描路径单行中间省略，显示最多每 100ms 更新，进度和完成反馈更平滑。
- 删除无人调用的旧列表适配器、废弃布局、一次性修补脚本和未使用的分页依赖。
- 模块根目录只保留安装、开机、操作、卸载入口与元数据；内部脚本集中于 `scripts/`，规则在 `config/`，原生引擎在 `bin/`，配套 App 在 `app/`。
- 脚本源码与打包名称一致，减少重复复制、临时改名和权限设置。App 同时识别新、旧模块布局。
- 保留清理规则、白名单、风险确认、扫描快照、定时策略和用户设置；目录整理不会重置个人配置。

## 更新

下载完整模块 ZIP 刷入并重启，模块包含同版本 App；若系统未能自动更新 App，可手动覆盖安装随版本发布的 APK。不要卸载旧 App 后再安装。

本版更改了模块目录，建议 App 与模块一并更新。新 App 可识别旧模块目录，以便分步更新。

验证包括核心回归、界面与单元测试、lint、正式签名校验、模块内外 APK 一致性，以及 Android 模拟器启动和覆盖升级。实体设备上的长期运行仍需继续观察。
