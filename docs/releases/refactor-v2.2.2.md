# 白泽 2.2.2 正式版

本版整合 2.0.0 正式版之后的清理、存储工具与安全性改进。内部构建号为 **30027**，沿用原 App 包名、模块 ID 和正式签名。

## 保护名单与旧设置恢复

- 修复外观设置迁移错误迁走非外观设置的问题；迁移只处理外观字段，不删除旧保护数据。
- 对已经迁走的历史保护规则提供只读核对与逐项确认恢复；不会自动添加用户后来删除的旧规则。
- 启动前检查旧设置完整性。设置损坏或保护状态无法确认时阻止 App 清理，保留原始内容和恢复线索；重启或修改外观不会静默解除这一保护。
- 安装包结果显示具体命中的应用、文件或上级目录保护规则，并提供对应管理入口。移除路径保护需要确认；应用保护勾选后自动保存，返回后重新扫描。

## 清理与文件工具

- 完善清理工作台、分类钻取、目录统计、搜索和批量选择；区分未索引、无法读取与真正的空结果。
- 普通文件回收站改为紧凑列表，增加数量/容量汇总、多选恢复和明确确认的清空操作。操作前重新核对记录与内容，已经确认的批次不会自动包含晚到项目。
- 完善重复文件保留策略、文件归类预览、图片另存压缩与独立规则包管理。
- 图片导出增加持久进度记录；中断后提供只读核对，保留原图与未完成副本，不自动重放导出。
- 修正历史记录、实际释放量与回收站占用显示；无法测量、失败、跳过与真实零释放分别表达。
- 完善页面返回、重复进入和权限拒绝后的状态处理。

## 安全边界

重新扫描和删除前重新核对内容身份；内容变化、读取异常或权限不足时保留文件并说明原因。缓存清理、Root/Shizuku 能力与普通文件访问分别判断，保留风险确认、白名单、扫描快照和关键数据保护。

## 安装与更新

- 仅更新 App：覆盖安装 `BaiZe-v2.2.2.apk`，不要先卸载旧 App。
- 使用定时自动清理：同时更新 `BaiZe-v2.2.2-Module.zip`，并按模块管理器提示重启。
- 使用过测试构建 30025 的用户，请先更新本版，并按提示核对需要恢复的保护规则，再进行清理。
- 模块内置 APK 与独立 APK 字节一致；下载同时提供 SHA-256 和正式签名证书信息。

## 验证范围

本版发布前执行 Android 单元/界面回归、lint、原生与 Shell/Python 回归、正式签名及版本检查、模块内外 APK 一致性，以及一次性 Android 模拟器安装和覆盖升级。发布后核对 Release 与下载镜像实际字节，再更新 OTA。

同一修复功能线的测试构建 30026 已通过 API 26/36 隔离文件操作，以及实际签名包 30025→30026 的旧保护恢复、取消不写入、损坏设置冷启动和再次重启检查。这些证据与本版签名构建检查分开记录，不代表所有品牌设备均通过验收。

厂商 ROM、真实 Root Binder、长期后台运行与存储空间耗尽仍需实际设备观察；模拟器验证不能替代全部真机兼容性测试。
