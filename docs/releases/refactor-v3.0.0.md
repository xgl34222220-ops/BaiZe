# 白泽 3.0.0 正式版

本版整合 2.2.2 正式版之后的界面统一、信息架构收拢、全页面重设计与扫描安全修复（#226、#227、#228、#229、#230），并做了一轮发布前的打磨。内部构建号为 **30029**，沿用原 App 包名、模块 ID 和正式签名。

## 界面与信息架构

- 去除重复页面与功能：只删重复、不删能力；被删页面的旧组件名全部保留为重定向，旧 Intent、桌面快捷方式、磁贴与通知入口继续可用。
- 入口收拢为“一键扫描 + 存储分析视图 + 自动任务 + 规则与保护 + 记录与回收站”；截图与录屏、旧下载、聊天媒体、自定义规则、根目录整理等能力并入统一扫描结果或存储分析视图。
- 首页、一键扫描结果、存储分析、根目录整理、记录、设置及全部二级页统一为同一套设计规范（间距、字阶、卡片圆角、分组标题、列表行高、图标托底、悬浮返回键与底部操作栏）。
- 首页补齐“上次扫描”四格（聊天媒体、安装包、大文件、重复文件）、自动清理下次时间与上次释放、回收站入口；“开始扫描”按钮在任务进行中显示进度并可点按取消。首页摘要只在专项页扫描完成或处理后写入，不新增任何启动扫描。

## 扫描与安全

- 相机、相册与录屏原件在分类视图中只读，不进全选与默认勾选；旧截图与录屏只按截图/录屏目录识别。
- 识别 QQ / 微信改名后的安装包副本（如 `xxx.apk.1`），并通过 Root 只读扫描 QQ / TIM / 微信的 Android/data 接收目录（有文件数、深度与时间上限，仅前台触发，开机不扫描）。
- **QQ / 微信 / TIM 聊天收到的安装包默认不勾选**，不进入“全选低、中风险”、分组勾选或一键自动清理；逐项确认后**移入回收站（隔离区）**，可在保留期内恢复，不再直接永久删除。
- 聊天媒体页里 Root 读取的 QQ / 微信 / TIM 共享目录文件可勾选，确认后由 Root 逐项核对路径与文件身份并移入回收站（隔离区）；`Cache_*` 缓存副本按低风险可全选，其余逐项勾选。
- 保留风险确认、白名单、逐项确认、扫描快照身份校验、回收站与隔离区、旧版保护恢复与旧入口重定向。

## 微信 / QQ 应用私有数据清理（#230）

- 聊天媒体页新增「应用私有数据（Root）」分区：**保留文字聊天记录，只删除图片/视频/语音/文件**。
- 微信只统计 `/data/data/com.tencent.mm/MicroMsg/<账号>/` 下的 image2、video、voice2、attachment、Download、sns、emoji 以及 MicroMsg/Download、cache；QQ / TIM 统计 NT 版 `files/nt_qq*/nt_data/` 下的 Pic、Video、Ptt、File、Emoji 与 cache。
- `*.db`、`*.db-wal`、`*.db-shm`、`EnMicroMsg*`、索引、配置、`shared_prefs/`、`databases/` 永不处理；每个文件在移动或删除前再次核对白名单、链接、文件类型与修改时间，目录需与扫描时的设备号 / inode 一致。
- 按 7 / 30 / 90 / 180 天+ 显示每个文件夹的占用；默认不勾选，可按应用分组勾选或逐个文件夹勾选，确认弹层列出将处理的文件夹与预估。
- 确认时可选先由 Root 执行 `am force-stop` 结束对应应用，避免清理时文件正被写入。
- 与回收站同在 /data 分区时先移入回收站（隔离区，3000 项 / 16 GB 上限），保留期内可恢复；超出上限或无法同分区移动的部分会明确提示“将永久删除”，只有单独勾选确认后才删除，否则原样保留。
- 只在用户点按时扫描，开机与启动 App 都不扫描，模块开机速度不受影响。

## 其他修复

- 设置 → 服务详情新增「重置扫描性能基准」入口（扫描明显变慢或换机后使用）。
- 删除未使用的内部接口（updateScheduler、ruleVersions）与未被读取的配置键 `app_task_max_minutes`；外观设置逐项核对均已生效。

## 发布前打磨

- 筛选把结果全部隐藏时，明确显示当前筛选并提供“清除筛选 / 显示全部”（安装包、应用缓存、保护名单），不再只显示“没有匹配”。
- 首页从未扫描时显示“尚未扫描 / 共可清理 —”；记录页空状态补充说明，累计耗时不再显示误导性的“0 秒”；清理页说明文案更直白。

## 安装与更新

- 仅更新 App：覆盖安装 `BaiZe-v3.0.0.apk`，不要先卸载旧 App。
- 使用定时自动清理：同时更新 `BaiZe-v3.0.0-Module.zip`，并按模块管理器提示重启。模块不会在开机时执行扫描。
- 模块内置 APK 与独立 APK 字节一致；下载同时提供 SHA-256 和正式签名证书信息。

## 验证范围

发布前执行 Android 单元/界面回归、lint、原生与 Shell/Python 回归、正式签名及版本检查、模块内外 APK 一致性，以及 Android 模拟器上实际签名包的安装、启动和覆盖升级。发布后核对 Release 与下载镜像实际字节，再更新 OTA。

厂商 ROM、真实 Root Binder、QQ / 微信各版本目录差异、长期后台运行与存储空间耗尽仍需实际设备观察；模拟器验证不能替代全部真机兼容性测试。
