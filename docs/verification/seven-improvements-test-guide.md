# 本轮七项改进测试说明

这是整轮测试分支的说明，不是正式发布。请先用可丢弃的测试文件验证，再处理需要保留的内容。

首页“整理空间”直接显示照片瘦身、重复文件、回收站；安装包、大文件、存储分析也保留在这里。自动任务记录、规则版本与试跑放在“设置”内。

## 1. 扫描与重复校验
- 在“重复文件”完成一次扫描，再重新扫描。文件身份未变且时间精度可靠时复用内容摘要，仍重新枚举系统索引。
- 改动一份文件后重新扫描，变化项重新校验。Android 8.0 或粗粒度时钟不复用摘要。
- 停止扫描后仅显示已完成校验的部分重复组，不声称全盘完成；处理前仍重新核对并确认。
- 处理多余副本后，只剩一份的组退出重复列表，保留副本不删除。

## 2. 普通文件回收站
- 入口：首页 → “回收站”；各文件工具顶部也保留“回收站”。
- 前台安装包、智能清理中的安装包、存储分类/下载文件、大文件和重复副本统一先移入回收站。
- 同卷原子移动；不支持安全移动或目录同步的卷拒绝移动，原文件保留。保护名单不确定时也不处理。
- 默认上限 5 GiB，可选 1/5/10 GiB。移动不立即释放空间。30 天后显示到期，仍须确认永久删除。
- 回收载荷不放在原文件父目录中，父目录被重命名或删除不会一起移除载荷；原目录不可用时拒绝恢复并保留载荷，请先恢复该目录。原路径已有文件时恢复到新的冲突副本，绝不覆盖。恢复中断可重试；移动后被其他应用改写的内容可经明确警告恢复当前副本。
- 无内容记录仅在所在卷可用且内容确实不存在时可清理，不操作原文件。
- 载荷放在对应共享存储卷的受保护隐藏目录，隐藏不代表私有；其他具有文件访问权限的应用仍可能访问。卸载或清空白泽数据会丢失恢复记录，请先恢复或清空。Root 高风险隔离区仍保留原独立管理入口；模块自动清理原有策略不在此改为回收站。

## 3. 保留偏好
- 入口：首页 → 重复文件 → 等待扫描结束 → “设置保留偏好”；组内可点“保留这份”。
- 重复文件页可选择优先相机目录、明确目录、最新或最早副本；“保留这份”可以逐组覆盖偏好。
- 更改偏好会清空勾选；每组始终至少留一份。目录/日期不代表已证明是原件。图片可查看缩略预览。

## 4. 自动任务可解释性
- 入口：设置 → 管理与维护 → “自动任务记录”（30017 修复入口遗漏；30016 没有可达入口）。
- 后台健康详情展示最近执行、等待/跳过原因和下次检查/计划时间。
- 息屏、充电、任务锁、服务故障等原因保留记录；重复心跳不反复生成相同记录。
- 电量不可读取且设置了最低电量时等待，不把未知电量当成满电。
- 当前测试包含 121 个合成安装包以及调度条件/故障/并发回归。模拟器、主机模拟与真实 OEM Root 手机是不同验证层级，未声称所有手机完成验收。

## 5. 目录与增长
- 入口：首页 → 存储分析总览，向下滑到“目录占用”和“最近谁长胖了”；第一次完整扫描仅建立基线。
- 存储分析从存储卷逐级进入目录，文件列表仅显示当前目录直接文件；目录统计含后代。
- 第二次完整扫描可比较目录及 Android 归属目录中的应用容量变化。
- 不同卷、未完成/截断扫描、身份未核对等不生成误导性增长。统计只覆盖系统已索引文件，不代表应用全部私有数据。

## 6. 独立规则与试跑
- 入口：设置 → 管理与维护 → “规则版本与试跑”（30017 修复入口遗漏；30016 没有可达入口）。
- “选择本地规则包”可导入本地签名规则包，确认文件差异后启用，或回滚上一版/恢复内置规则。
- 验证当前已安装白泽的发布者证书，不接受仅凭哈希的外来包。规则版本只改变前台扫描；无新增网络权限、账号或服务端。
- 自定义文件规则先只读预览再明确启用，也可全部停用；仅文件名支持 *，不扩展同名目录。#、路径首尾空白和不安全路径拒绝。
- 试跑不能替代正式扫描的保护名单和风险核对，启用规则不等于授权删除。规则包格式另见 offline-rule-bundle-format.md。

## 7. 照片瘦身
- 入口：首页 → “照片瘦身”；存储分析的“打开照片瘦身”和图片详情的“照片瘦身预览”也保留。
- 普通 SDR/sRGB JPEG 可选择质量和最长边上限，先预览再选择位置另存。
- 原图保持不变，新副本移除 EXIF/定位/拍摄时间并校正方向。两份都保留会增加当前占用，不谎报即时释放空间。
- HDR、动图、实况、未知扩展、特殊色彩及其他不支持格式拒绝处理。输入不超过 32 MiB/4000 万像素，解码采样限制内存。
- 没有节省空间时不导出；旋转或导出中断后不声称成功，用户应核对目标是否完整。
