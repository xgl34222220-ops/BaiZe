# Alpha 22 改动摘要

- 新增 Compose 启动页，复用洛书 MIUIx 的色彩、玻璃卡片、标题层级和悬浮底栏结构。
- 默认使用稳定的蓝紫主题，不再让 Monet 高饱和颜色主导首页。
- 背景采用静态渐变光斑，不使用实时模糊和持续动画，减少 WebUI 式卡顿感。
- 首页重新组织为状态 Hero、真实存储、主清理按钮和四个清理入口。
- 五类独立计划改为折叠式卡片，周期仍支持 1～720 小时，并提供 1/6/12/24 小时快捷值。
- 累计次数、累计释放、文件、空文件、空目录、碎片和耗时继续从模块状态永久读取。
- 保留 Alpha 21 XML 页面作为非启动回退页；清理脚本、RootService 和删除安全边界未改动。
