# Alpha 25 改动摘要

- 补全 `BaiZeRootService` 的 Manifest 声明，修复应用缓存 Root 引擎无法绑定、首页长期停留在“正在连接双 Root 快照引擎”的问题。
- 扫描结果清理改为只要求对应快照所属的引擎在线；只有安全项目快照时，不再错误弹出“应用缓存引擎尚未连接”。
- 必需引擎短暂断开时保留 30 分钟快照，重连后继续消费本次结果，不回退到全盘扫描。
- 首页连接标题与真实状态同步；引擎未就绪时不再假显示“清理引擎已连接”。
- 扫描完成后自动定位结果卡片，并增加动态底部安全间距，避免悬浮导航遮挡清理按钮与说明。
- App 与模块版本升级为 `2.0.0-alpha25` / `20500`，模块产物名为 `BaiZe-v2-Alpha25-Module.zip`。
