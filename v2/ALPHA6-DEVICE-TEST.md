# 白泽 v2 Alpha 6 设备测试清单

## 日常流程

1. 首页点击“立即清理”只启动一个任务。
2. 任务自动处理已启用的应用缓存、空项目、规则垃圾和残留碎片。
3. 全程不进入分类页，不要求逐项勾选。
4. 完成后首页显示真实释放量、文件/目录数量和任务耗时。
5. “仅扫描”只生成审计结果，不删除内容。

## 自动清理

1. 计划页保存后写入 `/data/adb/baize-v2/config.conf`。
2. 模块 `service.sh` 常驻并启动 `scheduler.sh`。
3. 间隔模式与每日固定时间模式互斥。
4. 息屏、充电、系统空闲、最低电量和温度条件实际阻止或放行任务。
5. 定时任务状态写入 `/data/adb/baize-v2/scheduler.env`。

## 高风险工具

深度规则与卸载残留继续要求单独扫描、近期快照和明确授权，不加入普通一键清理。

## UI

- 顶部内容必须位于状态栏下方。
- 首页采用旧版 WebUI 的信息顺序：存储概览、立即清理/仅扫描、专项工具、运行概览、调度状态。
- 底栏仅保留首页、计划、记录、设置四项。
- 详情页使用紧凑返回按钮和标题，不出现 Alpha 5 的超大圆形返回按钮。
