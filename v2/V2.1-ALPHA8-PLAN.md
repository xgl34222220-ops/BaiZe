# 白泽 v2.1.0 Alpha 8

## 目标

- 清理页不再暴露串行/双工作进程选择，始终由模块自动学习与回退。
- 手动缓存扫描继续通过 `one-pass-scan.sh`，与后台扫描共用同一性能基准。
- 受保护共享目录不扫描普通文件，但会只读检查其内部目录壳，从而发现真实空目录。
- 新增原生“文件归类”工具，扫描所有明确命名为 Download / Downloads / 下载的目录。

## 文件归类范围

- `/data/media/<user>` 公共存储及厂商、应用自建目录。
- `Android/data/<包名>` 与 `Android/media/<包名>` 内的下载子目录。
- Root 可读取的 `/data/user/<user>/<包名>` 与 `/data/user_de/<user>/<包名>` 下载子目录。

## 安全边界

- 扫描只建立 30 分钟不可变移动计划。
- 执行时重新校验 `lstat` 设备号、inode、大小和修改时间。
- 不跟随符号链接，不覆盖同名文件。
- 跨文件系统移动使用临时文件、`fsync` 和 SHA-256 校验。
- 数据库、锁文件和未完成下载文件默认跳过。
- 上一次成功归类保存可撤销记录；目标文件发生变化时拒绝撤销。
- 文件归类只由用户手动触发，不加入后台自动清理。
