# 白泽 v2 架构

## Alpha 2 边界

- 原生 Android App 负责界面、分页、勾选和本地白名单。
- libsu RootService 运行在独立 Root 进程中。
- AIDL 只传递扫描摘要和最多 100 条的分页 JSON，避免 Binder 大事务。
- 发现阶段只验证真实且非空目录，不递归读取内容。
- 大小和文件数在打开当前页时延迟统计，每目录最多 1.5 秒、每页最多 8 秒。
- Root 服务使用 Java NIO 直接遍历，不调用旧版 Shell 扫描器，不依赖 WebUI。
- 不跟随符号链接，不提供删除接口。
