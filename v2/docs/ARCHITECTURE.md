# 白泽 v2 Alpha 21 架构

## 分层

- Android App：MIUIx 原生界面、通知权限、计划配置、历史记录和人工确认。
- libsu RootService：AIDL 边界、分页扫描、安全删除、模块状态和累计统计。
- 模块脚本：开机调度、五类独立周期、完整规则清理、保护判断和定时通知。
- `/data/adb/baize-v2`：配置、白名单、累计统计、最近 100 次明细和扫描快照。

## 性能策略

- 首页不递归扫描全盘；容量由 `StatFs` 即时读取。
- 普通一键清理由成熟脚本按已知根目录和规则索引执行，不先计算每个文件的完整大小。
- 原生候选项按快照分页读取，Binder 不传递大文件列表。
- 背景渐变和玻璃表面静态绘制；底栏只动画位移、缩放和透明度，不做逐帧模糊。
- 同一 RootService 任务串行执行，并支持安全停止，避免多个扫描器争用存储。

## 统计语义

- `totals.env` 保存整个安装周期的累计次数、字节、文件、空文件、空目录、碎片和耗时。
- `history.tsv` 只保留最近 100 次任务明细，清空明细不会清空累计统计。
- Shell 清理和原生智能清理都会更新同一套累计数据。
- `module.prop` 的说明会在成功清理后同步累计释放量和项目数。

## 调度语义

- 总开关之外，缓存、空项目、规则垃圾、碎片和深度安全项各自保存开关及 1～720 小时周期。
- 息屏、充电、系统空闲和最低电量作为公共执行条件。
- 手动清理只读取现有配置，不写入调度或规则默认值。
- 深度定时仅执行安全级规则；需要人工确认的高风险候选项不进入后台任务。

## 通知

- App 发起的任务使用 Android `NotificationChannel`，Android 13 及以上先请求通知权限。
- 后台定时任务由 Root 模块脚本发送通知，App 触发时脚本通知被抑制，避免重复。
- 通知包含释放空间、文件、空文件、空目录、碎片和耗时，点击返回白泽首页。
