# 白泽 v2 架构草案

## Alpha 1 边界

- 原生 Android App 负责界面和任务状态。
- libsu RootService 负责独立 Root 进程与 Binder IPC。
- AIDL 负责 App 与 Root 服务通信。
- 扫描只枚举缓存候选目录，不递归读取内容。
- 模块仅提供开机状态与模块管理器启动入口。
- 本阶段不执行删除。

## 后续阶段

1. Alpha 2：C++/Rust 扫描核心、规则路径树、分批结果回调。
2. Alpha 3：扫描快照、白名单、单项选择和安全删除。
3. Beta 1：模块定时任务、后台通知、卸载残留。
4. Beta 2：规则更新、诊断包和兼容性测试。
