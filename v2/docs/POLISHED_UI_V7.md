# 白泽 v7 界面精修

本次只调整呈现与交互布局，清理引擎、规则、选择范围、风险判定、扫描结果有效期、定时策略及已有设置值保持不变。

- 默认品牌色 #1E6FFF，浅色容器 #EBF2FF，容器文字 #0B4FD9；背景 #F7F8FA，卡片纯白、16dp 圆角和微投影。深色、纯黑与自定义主题仍可使用。
- 首页数据采用 44sp 半粗数字与 18sp 单位，基线对齐；辅助路径采用 12sp 单行中间省略，完整内容保留在详情。
- 清理底栏正常字号下内容高度 80dp（不含外边距、系统手势区），单行计数、全选和胶囊主按钮。大字体允许适当增高。
- 所有应用内确认/筛选弹窗统一 28dp 圆角，灰底取消、主色确认；内容可滚动，按钮固定，支持键盘避让。支持的设备按外观设置使用背景虚化，其他设备使用暗化背景。
- 动态路径展示最多每 100ms 更新一次，不丢弃引擎事件或修改日志。渐变进度使用绘制层动效，系统关闭动画或性能降级时减弱动效。
- 统一 24×24、2dp 圆角线性分类图标与 40dp 浅底托片；统一低对比矢量空状态。
- 定时选项改为单行横向滚动，保留全部原周期；记录页的体积与状态右对齐。
- 界面风格名称改为“灵动 / 经典”，清除其他产品的宣传、对标名称。扫描到的真实应用名称和完整路径仍准确展示；第三方许可文件保留。

验证：核心回归、现有选择/筛选/高风险确认交互、正常字号底栏高度、窄屏大字体弹窗可达性、扫描路径稳定行高及末次更新、实际页面渲染。安装包交付前还需通过 CI 编译、lint 与签名校验。
