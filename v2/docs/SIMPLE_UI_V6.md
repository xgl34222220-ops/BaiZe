# v6：精简入口与按钮

根据“按钮太多、没用的可以去掉”的反馈，精简已有流程，不增加新功能入口。

- 首页整理区从 9 个入口减至 4 个：安装包、大文件、重复文件、存储分析。深度清理/卸载残留/文件归类放在清理页；白名单放在设置页。
- 首页只留一个主操作；重新扫描、收起结果和刷新状态放进右上角菜单。未安装自动化模块时不展示首页自动化卡片，仍可从清理页查看自动化设置。
- 清理页移除重复安装包入口；即时缓存与规则审计归入默认收起的高级工具。
- 存储与安装包页保留搜索，把类型、门槛、排序和安装状态放进一个筛选入口。弹窗点“应用”才生效，“取消”不改变结果或已有勾选。
- 已有扫描结果时，将重复扫描改为标题栏图标，底部保留全选和清理；安装包扫描范围与输出折叠在扫描详情中。
- 扫描工作台合并全选与取消全选，放入固定底栏；仅选中风险、重扫、白名单和说明收进菜单。高风险仍由用户逐项选择和确认。
- 设置页移除重复的历史、诊断和续清入口；连接与诊断从状态卡进入，续清留在诊断页。
- 两种外观共用同一页面结构，删除旧的重复页面实现，避免切换外观后又出现多余入口。

清理引擎、规则、定时策略和既有图标未改动。状态栏/挖孔安全区和固定底栏继续沿用。

验证：更新原有操作与渲染检查，新增筛选“取消不改选择、应用后只选当前结果”的交互验证。最终以 Android CI、核心回归和签名配套包校验结果为准。
