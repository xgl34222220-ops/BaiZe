# 单页扫描与清理工作流

## 用户可见的变化

工作台承接同一任务的扫描、逐项选择、清理和实际结果。分类概览只筛选同一批候选，不再次扫描、不另开结果 Activity。历史记录可读，失效快照不可执行。清理完成显示实际删除字节和文件数，不把扫描估计当作释放量。

页面保留一个固定主操作。列表视口止于底栏上方；搜索、应用展开状态、筛选条件可以恢复。搜索键关闭键盘后继续核对文件。长安全说明置于“扫描说明”及项目详情，高风险单独选择和二次路径确认不变。

## 官方交互依据

- [SD Maid SE 官方入门](https://github.com/d4rken-org/sdmaid-se/wiki/Tutorial)：Quick Access 扫描后按工具分类查看结果、排除要保留的文件，再执行清理。参考的是同批结果的渐进查看，不复制其页面或代码。
- [SD Maid SE 排除规则](https://github.com/d4rken-org/sdmaid-se/wiki/Exclusions)：可直接在结果中排除项目；应用、路径规则有不同作用范围。白泽仍在项目详情提供白名单入口，并保留引擎重新校验。
- [SD Maid SE AppCleaner](https://github.com/d4rken-org/sdmaid-se/wiki/AppCleaner)：应用级缓存结果及大小、时间等筛选帮助控制范围，系统应用清理并非默认无风险。
- [Files by Google 临时文件](https://support.google.com/files/answer/9713869?hl=en)：分类卡片呈现容量，清理前确认，并明确永久删除后果。
- [Files by Google 重复文件](https://support.google.com/files/answer/9764075?hl=en)：明确原件、选中文件、底部选中数量和确认。白泽只借鉴清晰的选择范围，不承诺所有 Root 删除可放入回收站。

资料核对日期：2026-09-30。上述参考产品的行为不代表白泽已经实现相同扫描范围或恢复能力。

## 验证重点

- 分类概览合计不得重复计算候选；筛选不得改变已经明确选择的 ID
- 低、中风险批量选择不能把高风险或保护项带入；高风险确认不能跨快照复用
- 完成阶段显示实际删除数；失败、保护及变化的文件仍留有解释
- 搜索、筛选和展开状态重建后保留，重建本身不发起扫描
- 大字体、窄屏、深色和无模糊降级下，唯一主按钮和项目选择可达
- Activity 导航、运行中 Back、重复点击、权限返回及后台任务生命周期由独立路由/session 回归验证；无 Root 模拟器不能证明真实设备上的 Root 文件删除结果
